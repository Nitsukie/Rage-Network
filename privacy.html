DATA PROTOCOL

PRIVACY

Last updated: July 27, 2026

1. Data we may process

Rage Network may process Discord user IDs, server IDs, role IDs, channel IDs, command interactions, moderation records and technical logs required to operate requested features.

2. Why data is used

Data is used to provide bot functionality, manage access, prevent abuse, maintain security, troubleshoot errors and improve reliability.

3. Data we do not request

Rage Network does not request passwords, payment card details, banking credentials or Discord account login credentials.

4. Storage and retention

Data is retained only for as long as reasonably necessary for the relevant feature, security requirement or legal obligation. Logs may be deleted or anonymized when no longer needed.

5. Sharing

Data is not sold. It may be shared only with service providers necessary to operate the bot, server administrators where required for moderation, or authorities when legally required.

6. User requests

You may request access to, correction of or deletion of stored personal data where applicable. Submit the request through the Support page and include your Discord user ID.

7. Security

Reasonable technical and organizational measures are used to protect stored information. No online system can guarantee absolute security.

8. Changes

This policy may be updated to reflect changes to Rage Network, legal requirements or data practices.
