# Rage Network Website

Static GitHub Pages website for Rage Network.

## Upload to GitHub

Upload these files to the root of your `Rage-Network` repository:

- `index.html`
- `style.css`
- `script.js`
- `terms.html`
- `privacy.html`
- `support.html`

GitHub Pages will automatically rebuild the website after the commit.

## Before Discord verification

Replace the placeholder support information in `support.html` with:
- an official support Discord invite, or
- a dedicated support email.

Review the Terms and Privacy Policy so they accurately match what your bot actually stores and does.
